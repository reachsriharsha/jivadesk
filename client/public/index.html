🚀 API Endpoints

POST /api/auth/register

Register a new user (doctor/admin/receptionist)

POST /api/auth/login

Login and receive JWT token

GET /api/patients

Get all patients (requires authentication)

POST /api/patients

Create a new patient record

GET /api/appointments

Get appointments with filters (date, doctor, status)

POST /api/invoices

Create invoice with automatic GST calculation

GET /health

Check API health status
