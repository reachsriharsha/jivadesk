# JivaDesk UI/UX Design Document

## Design System

### Colors

```css
/* Primary */
--primary-50: #eff6ff;
--primary-100: #dbeafe;
--primary-500: #3b82f6;
--primary-600: #2563eb;
--primary-700: #1d4ed8;

/* Neutral */
--gray-50: #f9fafb;
--gray-100: #f3f4f6;
--gray-200: #e5e7eb;
--gray-500: #6b7280;
--gray-700: #374151;
--gray-900: #111827;

/* Semantic */
--success: #10b981;
--warning: #f59e0b;
--error: #ef4444;
--info: #3b82f6;
```

### Typography

- **Font Family:** Inter (system fallback: -apple-system, sans-serif)
- **Headings:** 600-700 weight
- **Body:** 400-500 weight

| Element | Size | Weight |
| ------- | ---- | ------ |
| H1      | 24px | 700    |
| H2      | 20px | 600    |
| H3      | 16px | 600    |
| Body    | 14px | 400    |
| Small   | 12px | 400    |

### Spacing

Base unit: 4px

- `xs`: 4px
- `sm`: 8px
- `md`: 16px
- `lg`: 24px
- `xl`: 32px

## Component Library

### Buttons

| Type      | Usage          | Style                  |
| --------- | -------------- | ---------------------- |
| Primary   | Main actions   | Blue bg, white text    |
| Secondary | Cancel, back   | Gray border, gray text |
| Danger    | Delete actions | Red bg, white text     |
| Ghost     | Subtle actions | No bg, blue text       |

### Form Elements

- **Input:** Border, rounded-md, focus ring
- **Select:** Dropdown with chevron
- **Textarea:** Resizable, min 3 rows
- **Checkbox/Radio:** Custom styled

### Feedback

- **Toast:** Top-right, auto-dismiss
- **Modal:** Centered, backdrop blur
- **Loading:** Spinner + text

## Responsive Breakpoints

| Breakpoint | Width      | Layout                    |
| ---------- | ---------- | ------------------------- |
| Mobile     | < 640px    | Single column, bottom nav |
| Tablet     | 640-1024px | Collapsible sidebar       |
| Desktop    | > 1024px   | Full sidebar              |
